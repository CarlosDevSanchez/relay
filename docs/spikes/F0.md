# F0 spikes (claude 2.1.311, macOS)

## 1. `claude auth status`
`CLAUDE_CONFIG_DIR=<dir> claude auth status --json` (JSON is the default; `--text` gives prose). Exit code 0 in every case tried, so parse stdout, not the exit code. stderr may carry noise (e.g. "Claude configuration file not found at .../.claude.json" for a dir whose `.claude.json` is missing) while stdout is still valid JSON.

Logged in (pro/team):
```json
{ "loggedIn": true, "authMethod": "claude.ai", "apiProvider": "firstParty", "analyticsDisabled": false,
  "projectsDirectory": "<dir>/projects", "configDirectory": "<dir>",
  "email": "<string|null>", "orgId": "<string|null>", "orgName": "<string|null>", "subscriptionType": "pro|team|..." }
```
`email`/`orgId`/`orgName` can be `null` (seen on a team account whose `.claude.json` was missing). Plan = `subscriptionType`.

Empty fresh dir: `{ "loggedIn": false, "authMethod": "none", "apiProvider": "firstParty", "analyticsDisabled": false, "projectsDirectory": ..., "configDirectory": ... }` (no email/plan keys). `--text` prints `Not logged in. Run claude auth login to authenticate.`

## 2. Login
`claude auth login [--claudeai | --console] [--email <email>] [--sso]`; also `auth logout`, `auth status`. It is an interactive/browser flow (opens the OAuth page), so Relay runs it inside a PTY with `CLAUDE_CONFIG_DIR` set and the user finishes it in the browser. Not completed here (not probed beyond `--help`).

## 3. Transcript usage and rate-limit lines
Assistant line: `{"type":"assistant","timestamp":"2026-10-09T03:02:02.543Z","message":{"model":...,"usage":{"input_tokens":2,"output_tokens":233,"cache_creation_input_tokens":21063,"cache_read_input_tokens":24680,"output_tokens_details":{...},"server_tool_use":{...},"service_tier":"standard","cache_creation":{"ephemeral_1h_input_tokens":..,"ephemeral_5m_input_tokens":..},"iterations":[...]}, "content":[...]}, ...}`. Relay sums `input_tokens + output_tokens + cache_creation_input_tokens + cache_read_input_tokens`. Streaming/duplicated lines and sessions copied between accounts can make this an approximation.

Quota hit: top-level `"type":"assistant","isApiErrorMessage":true,"error":"rate_limit","apiErrorStatus":429`, `message.model":"<synthetic>"`, zeroed `usage`, `message.content[0].text`:
`You've hit your session limit · resets 1:10am (America/Bogota)`
Only the "session limit" variant exists in the local transcripts (also in subagent transcripts, `isSidechain:true`). Weekly/other variants are NOT observed; Relay matches generically `hit your (\w+) limit · resets (.+)` and keeps the raw reset text.
